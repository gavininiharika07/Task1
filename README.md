Basic Calculator in C

A simple command-line calculator built using the C programming language. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

User-friendly command-line interface

Division-by-zero error handling

Requirements

Before running the project, make sure you have:

A C compiler such as GCC

A terminal or command prompt

Installation & Usage
1. Clone the Repository
git clone <gavininiharika07-url?


2. Compile the Program
gcc calculator.c -o calculator

3. Run the Program

Linux / macOS:

./calculator


Windows:

calculator.exe

Concepts Used

This project demonstrates basic C programming concepts, including:

Variables and data types

Arithmetic operators

Error Handling

The program checks for division by zero and displays an appropriate error message instead of performing an invalid calculation.

Purpose

This project is designed as a beginner-friendly C programming project for understanding basic programming concepts and arithmetic operations.
